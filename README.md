# 🌟 StarDazzler

> A 2D space shooter game built with Python and Pygame.

---

## Overview

StarDazzler is a fast-paced 2D space shooter where the player navigates through cosmic formations of enemies on a journey to the planet Uranus.

The game features particle effects, dynamic enemy formations, progressive difficulty, and a level-up system.

---

## Features

- **Multiple Enemy Types** — Scouts, fighters, cruisers, and bosses
- **Enemy Formations** — Triangle, square, pentagon, hexagon, and final boss wave
- **Progressive Difficulty** — Speed and enemy strength increase over time
- **Particle Effects** — Explosions and engine trails
- **Level-Up System** — Gain more bullets and stats as you progress
- **In-Game UI** — Health bar, score, progress tracking, and journey indicator

---

## Installation

### Prerequisites

- Python 3.10 or higher
- pip (Python package manager)

### Step 1: Clone the Repository

    git clone https://github.com/faidalzahraam-pixel/StarDazzler.git
    cd StarDazzler

### Step 2: Install Dependencies

    pip install -r requirements.txt

### Step 3: Run the Game

    python StarDazzler2614.py
